# Automatic Clear Cutting

Automatically marks trees, rocks, cliffs and other obstacles for deconstruction, so your construction robots clear the ground ahead of your expanding base.

## Features

### Roboports
Whenever a roboport is built or upgraded, by hand or by robots, everything configured to be cleared within its construction area is marked for deconstruction.

### Around the player
With a personal roboport equipped, the area within its construction range is cleared continuously as you move around.
- Toggle it with the button on the shortcut bar, or with `SHIFT + ALT + C` (can be rebound under Controls).
- Off by default and set per player.
- The button is greyed out while no personal roboport is equipped.

## Settings
All settings are map settings and apply to every player.

| Setting | Default | Description |
|---|---|---|
| Exclusion margin | 1 | Number of tiles to skip along the edge of the construction area, since objects straddling the border may be marked but not reachable by robots |
| Rocks | On | Rocks, vents, ice formations, etc. |
| Cliffs | On | Robots need cliff explosives to remove these |
| Items on ground | Off | Loose items on the ground |
| Creature remains | On | Shells, husks, stromatolites, etc. |
| Ruins | On | Ruins and other building remains |
| Plants | Off | Re-plantable flora and similar, like Yumako and Jellystem on Gleba |
| Other | On | Objects that don't fit any of the above categories |

Trees are always included.

## Mod support
Besides the base game and Space Age, objects from the following mods are recognized:

Abacayba, Alien Biomes, Apia, Arcanyx, Carna, Cerys, Corrundum, Crucible, Eneas, Foliax, Igrys, Khemia, Lignumis, Maraxsis, Moshine, Muluna, Muria, Obsidiax, Omnia, Paracelsin, Pelagos, Planetaris: Arig, Planetaris: Hyarion, Planetaris: Tellus, Rabbasca, Ribbonia, Rubia, Tenebris Prime, Vesta

Missing something from a mod you use? Open an issue with the mod and the object's name.
